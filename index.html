Program structure

This program covers the full CDM lifecycle — from regulatory foundations and study setup through data collection, cleaning, quality control, and reporting. Each module contains lessons, use cases, and exercises. The SQL and Python tabs contain hands-on practice problems based on real clinical data scenarios.
